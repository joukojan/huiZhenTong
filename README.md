### 慧诊通平台（大模型应用）

- **项目简介**：一款基于 LangChain4j 的 AI 医疗伴诊与预约平台，面向患者健康咨询、科室分导诊、预约挂号和取消预约等就医服务场景，实现从自然语言咨询到后端预约业务操作的 AI 应用闭环。
- **技术栈**：SpringBoot、LangChain4j、LLM、Embedding、RAG、MongoDB、MyBatis、MySQL
- **技术亮点**：
  1.**RAG 医疗知识增强**：使用文本向量模型对医院资料进行向量化，并接入 Pinecone 向量数据库；在用户提问时召回相关知识片段，结合相似度阈值过滤无关内容，提升医疗问答和科室推荐的依据性。
  2.**多轮会话记忆持久化**：自定义 MongoStore ，按 memoryId 隔离不同用户会话，并使用窗口记忆控制上下文长度，支持用户在连续对话中逐步补全预约信息。
  3.**大模型工具调用业务落地**：封装一系列如预约挂号、门诊查询、查看报告等工具方法，让大模型根据用户意图自动选择调用后端 Java 方法，方法通过查询MySQL数据库确保可靠性。
