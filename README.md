### 慧诊通平台（大模型应用）

- **项目简介**： 一款基于 LangChain4j 的 AI 医疗伴诊平台，面向患者健康咨询、科室询诊、预约挂号等就医服务场景， 实现从自然语言咨询到后端数据库业务的 AI 应用闭环。
- **技术栈**： SpringBoot、 LangChain4j、 Embedding、 RAG、 MongoDB、 MyBatis、 MySQL、 Redis、 Lua
- **技术亮点**：
  1.**RAG 与记忆持久化**： 使用文本向量模型对医院资料进行向量化，并接入 Pinecone 向量数据库， 通过相似度召回与阈值过滤提升医疗问答的准确性。 自定义 MongoStore 按 memoryId 隔离用户会话并持久化上下文，支持连续对话中逐步补全个人信息。
  2.**模型工具调用与数据支撑**： 封装一系列如预约挂号、 科室查询、 患者分享等工具方法，大模型根据用户意图自动选择合适后端业务方法。 工具内部结合 Redis Hash 缓存患者登录， ZSet 维护门诊热度， Geo建模附近院区， Set 进行各类去重， 同时用 MySQL 存储完整内容， 让模型有事实依据。
  3.**号源预约高并发优化**： Redis 缓存排版信息，降低 MySQL 查询压力，通过逻辑过期解决缓存穿透击穿问题。使用 Lua 脚本保证号源扣减、资格校验、记录创建多步操作的原子性，防止出现超约重复约等问题，并通过消息队列异步写入预约记录，提升高并发访问下系统的稳定性和吞吐量。
